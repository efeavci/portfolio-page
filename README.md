# Portfolio – Efe Avci

Persönliche Portfoliowebseite für Web Engineering, ohne Framework oder Build-Schritt.

## Inhalte
- Startbereich und Über-mich-Abschnitt
- Zwei belegte Projekte: EWEB-Grundlagen und diese Portfoliowebseite
- Lernschwerpunkte HTML, CSS und JavaScript
- GitHub-Profil als Kontaktweg
- Hello-World-Demo und ein-/ausblendbare Projektdetails

## Lokal öffnen
`index.html` direkt im Browser öffnen. Alle benötigten Dateien liegen im Repository.
Keine Installation, externen Schriften oder Bibliotheken erforderlich.

## Kursbezug
- Einführung, Seite 77: externer CSS-/JavaScript-Code und Hello-World-Button.
- Web und UX, Seite 28: Text über DOM-Interaktion ein-/ausblenden; Beschriftung und Farbe ändern sich.
- Web und UX, Seiten 59–60: Flexbox-Navigation; unter 600px vertikal.
- Semantisches HTML, Sprunglink, Tastaturfokus, ARIA-Zustand und reduzierte Bewegung.

## Vor der Abgabe
Die vollständige Portfolio-Aufgabenstellung und ihr Bewertungsraster wurden nicht bereitgestellt. Daher ist dies eine erste Portfoliofassung, keine bestätigte vollständige Prüfungsabgabe.
Den sichtbar markierten persönlichen Profiltext mit Hintergrund, Interessen und Zielen ergänzen. Weitere Projekte und Kontaktangaben nur mit korrekten eigenen Daten hinzufügen.

## Prüfen
1. Navigation auf 320px, 599px, 600px und Desktopbreite prüfen.
2. Beide Projekt-Buttons bedienen: Alert sowie Details ein-/ausblenden.
3. Tab, Enter und Leertaste verwenden; sichtbaren Fokus prüfen.
4. Interne Abschnittslinks und GitHub-Links öffnen.
5. Auf kleinen Displays auf horizontalen Überlauf prüfen.
